How to add this signature to Outlook

New Outlook (Windows)

  1. Click the ⚙ Settings icon in Outlook.
  2. Go to Accounts → Signatures.
  3. Select New signature and give it a name.
  4. Paste the copied signature into the editor.
  5. Click Save, then select it as the default for new messages (and replies/forwards if desired).

Classic / Legacy Outlook (Windows)

  1. Open Outlook and go to File → Options → Mail → Signatures.
  2. Click New and name the signature.
  3. Paste the copied signature into the editor.
  4. Set it as the default for new messages (and replies/forwards if desired).
  5. Click OK to save.

Tip: If the logo does not appear immediately in the Outlook editor, click once inside the signature editor box and paste again.
